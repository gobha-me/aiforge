# Chat manual Ops failure matrix

- Missing broker/context/permission, foreign/stale authority or source: reject before read, append or provider work; preserve existing tool/policy binding.
- Active manual/model/child or pending repository/evidence work: refuse selection/submission without disturbing the work.
- Exact current manual run/invocation is required for port cancellation and approval. Old/model IDs cannot authorize the new target.
- Real manual allow, prompt, deny, source failure, cancellation and persistence refusal stay in the existing Chat kernel; no inference/model/context call after initial Chat open.
- Ordinary drain and manual pump make progress without duplicate events or dispatch, even when ordinary model polling is disabled.
- Failed/unavailable repository evidence does not cause manual host reads to attempt model continuation; subsequent ordinary turns retain all evidence gates.
- Off/unsupported-model/persona/model maxima and automatic counters stay unchanged. Explicit admin profile is separate from manual availability.
- Inspection/replay never collects, failed later work preserves original prior successful evidence, physical retirement does not manufacture idle capacity.
